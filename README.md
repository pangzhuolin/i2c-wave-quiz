# I²C 波形读图训练

给新生练习"看波形读 I²C"的单页小工具。数据取自 AHT20（7 位地址 `0x38`，触发测量命令 `0xAC`）的一次读写过程，按 5 段拆开：

| 片段 | 内容 |
|-|-|
| ① 起始 | SCL 高电平期间 SDA 下降 → 起始条件 S |
| ② 地址+写 | `0111 0000`（0x38 + W）+ 从机 ACK |
| ③ 命令 0xAC | `1010 1100` + 从机 ACK |
| ④ 读地址 | `0111 0001`（0x38 + R）+ ACK |
| ⑤ 数据+停止 | `0011 0011` + 主机 NACK + 停止 P |

每段配一道选择题，选完即时判定；右上角"出题模式：只看波形"会隐藏所有标注（位值、地址括号、ACK/NAK 文字、分段名），只留 SCL/SDA 两条线，适合投屏提问。

页面是单个自包含的 `index.html`，无依赖、无构建，双击也能打开。
